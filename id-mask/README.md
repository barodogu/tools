# 신분증 가림 도구 (id-mask)

신분증 사본의 주민번호 뒷자리 등을 검정 상자로 덮고, 워터마크를 넣어 평면화된 이미지/PDF로 저장하는 브라우저 도구.

## 원칙
- 서버 전송 없음 — 모든 처리는 브라우저 Canvas에서만 수행, 외부 라이브러리·요청 0건
- 저장 시 재인코딩으로 EXIF(GPS·기기정보·원본 썸네일) 자동 제거
- 모자이크/블러 미제공(복원 위험), 불투명 검정만 사용
- localStorage 등 브라우저 저장소 사용 안 함

## 지원
주민등록증, 운전면허증, 여권(구형·차세대), 외국인등록증, 장애인등록증, 모바일 신분증 캡처, 기타(직접 가리기)

## 파일
- id-mask.js — 본체 (불러오기 → 4점 투시 보정 → 템플릿 가림·수동 편집 → 워터마크 → JPG/PNG/PDF)
- id-mask-templates.js — 신분증별 가림 위치(보정 후 비율 좌표). 대략값이며 화면에서 확인·보정 전제
- id-mask.css — #idmask-app 범위 스타일 (idm- 접두어)
